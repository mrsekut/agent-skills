事業の数字を、面積や高さが数値に比例した SVG で描く。mermaid は大きさを比例させて描けないので、量・比率・推移の図は SVG で書く。

## 1. 数字を揃える

- ユーザーの入力・決算資料・記事から、売上高・売上原価・販管費・営業利益などを拾う。
- **整合を確かめる**。売上原価 + 販管費 + 営業利益 = 売上高 になるか、粗利 = 売上高 − 売上原価 になるかを計算し、合わなければ（営業外項目の混入、期のずれなど）ユーザーに確認する。
- 粗利率・営業利益率など、図で見せる比率は自分で計算しておく。
- 数字が足りないときは推測で埋めず、ユーザーに聞く。概算でよいと言われたら、図中に「概算」と明記する。

## 2. 型を選ぶ

| 型 | 選ぶ場面 |
|---|---|
| **損益の面積図**（売上 → 原価・販管費・利益の積み上げ） | 売上のうち何がどれだけ持っていかれ、いくら残るかを示す |
| **ウォーターフォール**（売上から利益への段々） | どの費用が利益を一番削っているかを順に追わせる |
| **時系列の棒グラフ / 積み上げ棒** | 伸びている・縮んでいる、内訳の比重が変わったを示す |
| **ユニットエコノミクス分解**（ツリー状の掛け算分解） | この数字はどの要素の掛け算で決まり、どこを動かせば効くかを示す |
| **構成比の100%積み上げ** | 総量ではなく割合の違いを複数社・複数年で比べる |

迷ったら、ユーザーが一番言いたいこと（「粗利率が高い」「販管費が重い」など）が一目で分かる型を選ぶ。

## 3. 描く

- **数値から座標・高さを計算して描く**。目分量で置かない（例: 100% = 400px なら 40% は 160px）。計算の前提（1% = 何px か）を SVG 内のコメントに残す。
- `viewBox` を指定し、幅は 800px 前後にする。
- 各ブロックに**値のラベル**（名前と数値）を付ける。凡例を探させない。
- 色は意味で揃える。同じ概念には常に同じ色を使う。既定は次の通り。
  - 売上高: `#7a7a8c`（灰）
  - 売上原価: `#e8a33d`（橙）
  - 販管費: `#5b8fd9`（青）
  - 利益: `#4caf7a`（緑）、赤字: `#d9534f`（赤）
- 粗利・粗利率のように複数ブロックにまたがる量は、括弧（ブラケット）とラベルで示す。
- `font-family` に `"Hiragino Sans", "Noto Sans JP", sans-serif` を指定する。
- 背景は白い `<rect>` で塗る（ダーク背景のビューアでも読めるように）。
- **金額は円で書く**。元資料が百万円単位でも `40M` のような表記にせず「4,000万円」「1億2,800万円」と書く。

最小サンプル（損益の面積図）: [examples/pl-area.svg](examples/pl-area.svg)。左列が売上原価40% / 販管費45% / 営業利益15%、右列が売上高100%で、粗利60%を括弧で示している。

## 4. 確認する

- `xmllint --noout <file>.svg` で構文を見る。
- `, resvg <file>.svg <file>.png`（Nix の `,` コマンド）で PNG にして Read で目視し、文字のはみ出し・重なり・小さすぎるブロックのラベル潰れがないかを見る。潰れる場合はラベルをブロックの外に出して引き出し線を付ける。

## 出力

- 保存先はユーザーの指定に従う。指定がなければカレントディレクトリに `<slug>.svg` で置く。
- 図を渡すときは、**読み方を1〜2文添える**（例: 「粗利率は60%と高いが、販管費が45%を食っているので営業利益は15%しか残らない」）。
