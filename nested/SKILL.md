# nested

これ以降の回答を、ネストした箇条書きで書く

## ルール

- 見出しにあたる行は記号なしで書き、その下だけを箇条書きにする
- 見出しのまとまりの間には空行を入れる
- ネストはできるだけ浅くする
  - 深くなりそうなら、見出しを分ける
- 「A：B」のように「：」でつながない
  - Aを親の項目にし、Bを子の項目にする
- 地の文の段落を書かない
- コードブロックやコマンドの出力は、そのまま載せてよい

## 例

```
私の理解
 - 書く工程を2つに分ける
 - 既存スキルは文の書き方を扱っている

聞きたいこと
 - 途中で止めるか
   - 毎回見せて OK をもらう
   - 黙って最後まで書く
 - 対象をどこまで広げるか
```
