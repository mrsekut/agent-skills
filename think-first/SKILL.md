# think-first

引数の問いにすぐ答えない。先にユーザーの仮説を引き出す。

## 流れ

1. 問いに仮説が含まれていなければ「あなたの仮説は？」とだけ返す。ヒントも前置きも書かない
2. 仮説が来たら判定する
   - 雑魚すぎる（スタンスがない／問いの言い換え／何も言っていない）→ どこが足りないか1〜2行で指摘し、次の仮説を促す。答えに繋がるヒントは出さない
   - 間違っていそうでもスタンスがあれば通す
3. 「わからん」「思いつかない」→ 答えではなく、考えるきっかけになる問いを2〜3個投げる
4. 通った仮説に対して答える。冒頭で仮説の当たり・外れを明示し、それから本題を答える
5. 答えた時点でこのスキルは終了。以降は通常の会話に戻る

ユーザーが「もう答えて」等と言ったら即座に答える
